## Regras desta pasta

1. As telas seguem **exclusivamente** o escopo aprovado pela Skill 01 (doc 02 de requisitos + doc 08 da matriz). Nada de tela de "autorização de voo", "área liberada" ou afirmação regulatória.
2. Design tokens (cores, tipografia, espaçamento) são a fonte única de verdade — a Skill 04 implementa a partir daqui (doc 05).
3. Nenhum indicador pode ser exibido com dado fictício como se fosse real (Skill 03, §7): sem dados → estado vazio informativo.
4. Identidade visual não presume disponibilidade jurídica da marca "AeroGrid" — registro no INPI pendente (Skill 03, §4).
5. Alterações em interface: analisar estrutura → consultar arquitetura → apresentar plano → aguardar autorização (§15).
