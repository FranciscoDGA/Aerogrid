## 5. Como registrar evidências

Para cada nova evidência, adicionar uma linha com:

- **Data**
- **Fonte** (empresa/personagem — anonimizar se necessário)
- **Tipo:** entrevista / demonstração de pagamento / uso espontâneo / fonte publicada
- **Trecho relevante** (citação ou resumo)
- **Impacto:** confirma / enfraquece / refuta qual hipótese
